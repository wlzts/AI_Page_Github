【曹继贤 AI_Page V8 部署最快路线】

你已经有仓库：https://github.com/wlzts/AI_Page

1. 先在 GitHub：Code -> Download ZIP，备份当前仓库。
2. 解压本 V8 ZIP。
3. 打开 AI_Page 仓库 -> Add file -> Upload files。
4. 把本 V8 解压后的根目录内容拖进去并提交到 main。
   注意：不要删除仓库里原有的 9 个 projects 子项目。
5. Settings -> Pages -> Source 改成 GitHub Actions。
6. Actions -> 等待 Deploy AI_Page to GitHub Pages 全绿。
7. 打开 https://wlzts.github.io/AI_Page/
8. GitHub Settings -> Developer settings -> Fine-grained tokens：
   只授权 AI_Page，Contents = Read and write。
9. Vercel 导入 wlzts/AI_Page。
10. Vercel 设置环境变量：
    GITHUB_OWNER=wlzts
    GITHUB_REPO=AI_Page
    GITHUB_BRANCH=main
    RESUME_DATA_PATH=projects/playable-resume/resume-data.js
    PROJECTS_DATA_PATH=projects-data.js
    GITHUB_TOKEN=你的Token
    ADMIN_PASSWORD=你的管理员密码
    SESSION_SECRET=至少32位随机字符串
    ALLOWED_ORIGINS=https://wlzts.github.io
11. Vercel Redeploy。
12. 打开 https://你的vercel域名/api/health，确认 configured=true。
13. 打开 https://wlzts.github.io/AI_Page/projects/playable-resume/?admin=1
14. 输入 Vercel API 地址和管理员密码。
15. 修改 -> 发布到 GitHub -> 等 GitHub Actions 自动部署。

完整排错与解释请看 DEPLOY_GITHUB.md。
