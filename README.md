# AI_Page V8 Integrated Edition

曹继贤的统一个人数字作品站：**AI 网页实验室 + 可玩的中文像素 RPG 简历 + 在线管理员后台**。

## 在线结构

- 根站：AI 网页实验室
- `projects/playable-resume/`：可玩简历
- `projects-data.js`：AI 作品统一数据源
- `projects/playable-resume/resume-data.js`：简历统一数据源
- `api/` + `server-lib/`：Vercel 在线管理 API
- `.github/workflows/pages.yml`：GitHub Pages 部署

## 重要：部署到现有 `wlzts/AI_Page`

你现有仓库已经有 9 个独立网页项目。上传 V8 时**不要删除这些目录**，直接将 V8 文件合并到仓库根目录即可。
